Sobre o Projeto

Este projeto demonstra a implementação de três medidas estratégicas de segurança em ambiente AWS, com foco em monitoramento, auditoria e aplicação de boas práticas.

A solução foi desenvolvida com o objetivo de fortalecer a governança em nuvem, aumentar a visibilidade operacional e reduzir riscos.
1️⃣ Amazon CloudWatch – Monitoramento

Coleta centralizada de logs
Monitoramento de métricas
Eventos em tempo real
2️⃣ AWS CloudTrail – Auditoria

Registro de atividades da conta
Rastreamento de ações de usuários
Armazenamento de eventos de API

3️⃣ AWS Trusted Advisor – Boas Práticas

Recomendações de segurança
Análise de performance
Otimização de custos

🎯 Objetivos do Projeto

Fortalecer a postura de segurança
Garantir governança e auditoria
Reduzir riscos operacionais
Aplicar boas práticas AWS
Melhorar eficiência do ambiente
